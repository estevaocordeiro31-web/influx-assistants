- lamp (abajur, luminária) / drawer (gaveta) / room (cômodo) / wall (parede, muro) / ceiling (teto)

**Clothes:**
- clothes (roupas) / shoe (sapato) / sneaker (tênis) / sock (meia) / T-shirt (camiseta)
- shirt (camisa) / blouse (camisa feminina) / pants (calça) / skirt (saia)
- sweater (blusa, suéter, pulôver) / coat (casaco) / glasses (óculos)

**Prepositions of Place:**
- in / inside the drawer (na / dentro da gaveta)
- out of the drawer (fora da gaveta)
- on the dresser (na / sobre a gaveta)

**Compound nouns:**

**Nouns always plural:**

## Imagem 28: Helping You + Dialog Samples - Lesson 10 (Página 55)
**Helping You:**
- you go downtown / you are downtown / you live downtown

**There is / There are:**
| | Affirmative | Negative | Interrogative |
|---|---|---|---|
| singular | there is | there is not / there isn't | is there? |
| plural | there are | there are not / there aren't | are there? |
